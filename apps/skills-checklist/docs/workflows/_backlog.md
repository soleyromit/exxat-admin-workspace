## Tasks from 2026-11-04 Aarti prototype review (Skill Tracking Discussion 2)

Source: `docs/research/meetings/2026-11-04-skill-tracking-discussion-2-aarti.md`

> Aarti gave direct corrective feedback on the prototype. Key correction: sub-selecting individual skills per student cohort is the wrong model — assign entire skill lists to groups. Also directed: course cloning must carry forward skill mappings, design must cover all 8 known domain variations, one clean happy path per screen by November 23rd.

|---|---|---|---|---|---|

No cherry-picking of individual skills per group. | Admin | Skills setup | P0 | Aarti: "sub-selection of skills from existing multiple lists— bullshit. This is not how it's going to happen."
