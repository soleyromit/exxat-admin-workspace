# Thursday demo flows (Sankalp, final list)

This is the binding scope and order for the Thursday meeting. Every walkthrough, screen fix and priority follows it. Sankalp's words, verbatim:

## Admin flow (configuration happy path)
1. Add skills to the library (1 at a time or bulk uploads)
2. Create tags and categories
3. Configure skills
4. Create groups of skills (non mandatory step)
5. Assign skills to student groups either one skill at a time or assign a group of skills if group of skills was setup
6. Configuring which skills are mandatory or recommended across different clinical courses

## Student (fulfillment happy path)
1. Where will they go to view the skills assigned to them? Will there be a central place or will they go course by course within their coursework section. "I think both would probably be needed to track overall progress vs fulfilling skills which are mandated per course."
2. Selecting the course > Viewing and selecting the mandatory skills > Reviewing the set of questions basis the configuration done by the admin for that skill > Self evaluation if required > Sharing the skills to preceptor/faculty or lab technician for review

"I think if we can have a happy path for configuration and fulfillment it should be good."
